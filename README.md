# 🎬 Кинорулетка / Movie Roulette

Сервис для тех, кто смотрит много кино, но каждый вечер мучительно выбирает, что включить. Вбиваешь список фильмов, крутишь колесо — и выбор делает судьба, а не ты.

Розово-чёрный эмо-интерфейс, колокольчики при прокрутке, салют на выпавшем фильме. Работает на русском и английском.

## Что умеет

### 🎡 Колесо
- Добавление фильмов пачкой — по одному на строку (дубли пропускаются)
- Колесо с анимацией, звоном колокольчиков и стрелкой, которая подпрыгивает на каждом секторе
- Окно с вердиктом судьбы: «Смотрю!» или «Не, крутим ещё»
- Опция «Убирать выбранный фильм из колеса»
- История — что судьба уже выбирала
- Перемешать / очистить список
- Запуск пробелом

### 🤔 Не знаю, что посмотреть
Тест в формате чата: настроение, компания, сколько сил, эпоха, страна и свободное пожелание. По ответам Claude подбирает 5 фильмов с объяснением, почему они подходят. Каждый фильм можно добавить в колесо или отправить туда сразу всю подборку и крутить.

> ⚠️ Этот раздел работает только когда страница открыта как артефакт в Claude — подбор идёт через встроенный в Claude вызов модели (`window.claude.use("sample")`). На GitHub Pages и в обычном браузере раздел покажет сообщение, что подбор недоступен; колесо и списки работают везде.

## Как запустить

Это одна HTML-страница без сборки и зависимостей.

- **Локально:** просто откройте `index.html` в браузере.
- **GitHub Pages:** залейте репозиторий на GitHub → *Settings* → *Pages* → *Deploy from a branch* → ветка `main`, папка `/ (root)`. Через минуту сайт будет доступен по адресу `https://<ваш-ник>.github.io/<имя-репозитория>/`.

## Как устроено

- `index.html` — всё в одном файле: разметка, стили и JavaScript
- Колесо и салют рисуются на `<canvas>`
- Звуки синтезируются через Web Audio API (никаких аудиофайлов)
- Шрифты — [Unbounded](https://fonts.google.com/specimen/Unbounded) и [Manrope](https://fonts.google.com/specimen/Manrope) из Google Fonts
- Список фильмов, история и язык сохраняются в `localStorage` браузера
- Тексты интерфейса на двух языках лежат в объекте `I18N`
